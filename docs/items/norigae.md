# 노리개와 길들임

## 보급형 노리개

사형수 전형을 제외한 협회원에게 기본 지급되는 **개인용 정신 방호 장비**다. 처음에는 규격화된 단순한 매듭과 장식으로 구성된다. 감당할 수 없는 정신적 위협이나 물리적 충격으로 손상될 수 있고, 손상 시 방호 성능이 약화된다.

**서여울은 사형수 전형 출신이라 공식 보급형 노리개를 지급받지 않았다.** 서여울이 지니게 된 초련의 유품과 협회 지급품은 별개의 사안이다.

## 길들임

오랜 착용과 이변 노출을 거치면서 보급형 노리개가 주인에게 적응하는 변화다. 매듭, 장식, 색과 재질뿐 아니라 **정신적 취약점을 보호하는 방호 기능**까지 달라진다. 사용자가 임의로 장식을 바꾸는 것과는 구분된다.

일정 정도 길들여진 노리개는 타인에게 반응하지 않는다. **주인이 사망한 뒤에도 타인을 보호하지 않는다.** 작동을 잃는 정확한 단계와 수선·교체·재지급 규정은 아직 미정이다.

## 초련의 노리개

초련의 노리개는 **덜 여문 곡식 이삭 세 줄을 묶은 삼작노리개 변형**으로, 글자가 없는 작은 타원형 회백색 옥패와 오래 사용한 매듭을 지녔다. 초련에게 길들여진 정신 방호 장비였으므로 다른 사람인 여울에게는 작동하지 않는다.

| 시점 | 행방 |
|---|---|
| 초련 생전 | 초련이 착용한다. |
| 초련 사망 직후 | **서여울이 손상된 노리개를 현장에서 챙긴다.** 기능은 몰랐으며 유품으로 여겼다. |
| 여울의 자수·수감 | 여울이 지녔으나 수감 과정에서 회수된다. |
| 2부 구조 후 | 여울이 Null에 소속될 때 **무극에게 돌려받는다.** 확보 경위는 의도적으로 밝히지 않는다. |

## 너울과의 구분

노리개와 너울은 서로 다른 유품이다. 너울은 여울이 초련처럼 살아 보려고 착용했다가, 자수하러 떠나기 전에 김설하에게 남긴다. 설하는 자신의 개인실에 걸어 두며 두 사람 모두 반환을 원하지 않는다.

이 작품의 최신 이미지 기준에서 **초련의 너울은 검은 갓의 챙 가장자리에서 검은 장막이 아래로 드리워지는 형태**다. 이전 프로필의 회백색 후드형 외형 제안보다 이후 사용자가 지정한 디자인을 우선한다.

## 미정

정신 방호의 정확한 적용 범위, 파손 시 추가 반응, 길들임의 정확한 단계, 재지급 규정, 귀환점 의식과의 직접 연동은 미정이다.
