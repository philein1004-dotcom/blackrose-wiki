# 어둑시니·그슨대 시험 이변

어둑시니와 그슨대가 등장하는 **공간형 이변**은 비사형수와 사형수 입사 시험에 공통으로 사용되는 시험장 **중 하나**다.

| 구분 | 비사형수 전형 | 사형수 전형 |
|---|---|---|
| 목적 | 적성 확인과 생존 판단 | 최초 탐사 생존 능력의 선별 |
| 입장 | 국민안전부의 특수 재난안전문자 | 원래 사형집행일보다 약 2주 앞서 강제 입장 |
| 수칙·단서 | 재난안전문자로 단계적 제공 | 제공하지 않음 |
| 생존 이후 | 적성에 따라 부서 배치 | 현실에서 사망 처리, 주로 사전답사부 배치 |

## 기원이 미정인 시험장

이 시험장이 협회의 관리 아래 놓인 **자연 발생 이변인지**, 연구·분석부가 **직접 개발하거나 개조한 이변인지 아직 확정하지 않았다.** 따라서 ‘협회가 완전히 설계한 시험장’으로 단정하지 않는다.

수칙 전문, 구체적인 지형과 탈출 조건, 개체 조우 방식, 서여울·이선의 실제 통과 장면, 최종 등급은 미정이다. 이전에 제안된 랜덤 조우·변형 지도 같은 구상은 확정 설정으로 제시하지 않는다.
