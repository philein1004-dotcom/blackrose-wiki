# 어둑시니·그슨대 시험 이변

협회가 완전히 관리하는 입사 시험용 이변 중 하나다. 어둑시니와 그슨대가 등장하며, 비사형수 전형과 사형수 전형에 서로 다른 방식으로 사용된다.

## 전형별 차이

| 구분 | 비사형수 | 사형수 |
|---|---|---|
| 목적 | 적성 검사 | 소모품 선별과 생존 능력 확인 |
| 입장 | 국민안전부 특수 재난안전문자 | 사형집행일 약 2주 전 강제 투입 |
| 수칙·단서 | 재난안전문자 형태로 제공 | 제공하지 않음 |
| 실패 처리 | 기억 소거 후 일상 복귀 | 사망 또는 사실상 폐기 |
| 생존 이후 | 적성에 맞는 부서 배치 | 사전답사부 배치, 사회적으로 사망 처리 |

## 게임·사건화 방향

- 고정된 한 장의 지도가 아니라 구조가 매번 변하는 탐색형 이변으로 운용 가능하다.
- 어둑시니와 그슨대는 지정 장소에 고정되지 않고 무작위 조우한다.
- 특정 조건을 충족하면 탈출 선택지가 열린다.
- 서여울은 본래 쓰러뜨릴 필요가 없는 개체와 정면으로 충돌하는 이례적 생존법을 보일 수 있다.

## 미정 사항

- 실제 수칙 전문
- 서여울의 구체적인 생존 장면
- 비사형수 시험에서 이선이 처음 법칙을 찢는 방식
- 최종 등급과 시험 관리 실패 시의 안전장치
