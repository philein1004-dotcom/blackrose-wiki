# 팔괘 8부서

블랙로즈는 팔괘에 따라 여덟 공식 부서를 두며, 팔괘 바깥에는 무극 산하의 비공식 특수부서 **Null**이 존재한다.

| 괘 | 정식 부서 | 현장 호칭 | 역할 |
|---|---|---|---|
| 건·하늘 | 공보부 | 건 | 대외 발표, 정보 통제, 재난 위장. 국민안전부·가람출판사·국제인문연구소와의 대외 업무를 관리한다. |
| 태·연못 | 인사부 | 태 | 인재 선발, 협회원 배정, 시험 생존자와 지원자 처리. |
| 이·불 | 연구·분석부 | 이 | 이변 분석, 기록 해석, 수칙서 작성과 개정. |
| 진·우레 | 이변탐사부 | 진 / 탐사A | 수칙서 기반 정식 탐사, 구조, 진압, 회수. |
| 손·바람 | 사전답사부 | 손 / 탐사B | 최초 진입, 위험 정보 수집. 사형수 생존자가 주로 배치되는 사망전대식 부서. |
| 감·물 | 관리부 | 감 | 사신수·고위험 자원·특수 사전답사 체계 관리. 사형수 전형 담당. |
| 간·산 | 기록부 | 간 | 현장 기록 저장, 사망 기록과 자료 보존·관리. |
| 곤·땅 | 후처리부 | 곤 | 현장 복구, 은폐, 사회적 흔적 제거. |

`탐사A`, `탐사B`는 편의상 쓰는 비공식 명칭이며 정식 명칭은 각각 **이변탐사부**, **사전답사부**다.

## 지휘 묶음

- **양**: 건·태·이
- **무극**: 진·손·Null
- **음**: 감·간·곤

무극의 관할과 Null의 비공식성은 별개다. Null은 **정식 팔괘 부서 수에 포함되지 않는다.**
