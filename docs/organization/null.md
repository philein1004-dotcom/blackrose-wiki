# Null

**Null**은 팔괘의 공식 조직도 바깥, 무극 산하에 존재하는 비공식 특수부서다. 공식적으로는 존재하지 않지만 중복 소속이 가능하며, 일반 부서보다 높은 정보 접근성과 비정형 권한을 가진다.

## 성격

- 팔괘의 균형에서 빠진 무극 산하의 숨겨진 부서다.
- 표준 업무 분류에 들어가지 않는 사건과 인물을 다룬다.
- 관리 대상이면서 실전 투입 자산인 인물을 운용할 수 있다.
- 정식 채용보다 **이미 업무를 수행한 사람에게 사후 통보하는 방식**으로 인원을 끌어들인다.
- 명령보다 기록, 빈칸, 이상한 문서를 미끼처럼 던지는 경우가 많다.

## 주요 인물

| 인물 | 관계 |
|---|---|
| 무극 | Null의 상위 존재. 부서의 비정형 영입과 기록 배치를 주도한다. |
| 서여울 | 관리 대상이자 실전 투입 자산. 일원처럼 임무를 수행하지만 보호받는 직원과는 다르다. |
| 김설하 | 검은 봉투 반송 사건을 이미 Null 방식으로 해결한 뒤 사후 편입되었다. |
| 초련 | Null과 이변탐사부의 중복 소속. 서여울의 인간성 회복을 시도했다. |

## 영입 논리

Null은 지원서를 받지 않는다. 무극이 남긴 문서나 분류 오류를 스스로 파고들고, 누구의 명령도 없이 해당 업무를 끝낸 순간 그 사람은 이미 Null의 방식으로 일한 것으로 간주된다.

> “임시 배속을 승인함. 사유: 이미 업무 수행 완료.”
