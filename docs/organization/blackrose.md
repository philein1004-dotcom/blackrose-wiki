# 블랙로즈의 정체

블랙로즈는 공식적으로 존재하지 않는 이변 대응 조직이다. 대외적으로는 여러 합법 기관의 얼굴을 빌리지만, 본질적으로는 인간 사회의 기관보다 **황룡이 세운 균형 장치**에 가깝다.

## 협회장 황룡

협회장은 인간이 아닌 이변 존재 **황룡**이다. 블랙로즈의 창설자이자 성황당과 조직 상징 체계의 중심이다.

현재 황룡은 직접 권한을 행사하지 못하며 인간 대리인이 권력을 장악한 상태다. 대리인은 부패한 정부와 결탁해 국민안전부까지 통제하고, 사형수 운용과 강제 영입을 제도화했다. 이는 황룡의 평화주의적 이미지와 충돌한다.

## 양·무극·음

| 존재 | 외형과 위치 | 현재 역할 |
|---|---|---|
| 양 | 흰 머리, 검은 눈의 단발 남성 인간형 이변 | 건·태·이를 산하에 둔다. 협회장에게 충성하지만 대리인의 권한을 수긍하는 편. |
| 무극 | 금발, 눈을 가리는 앞머리, 꽁지머리 | 진·손·Null을 산하에 둔다. 황룡의 분신이라는 비공개 설정이 있다. |
| 음 | 검은 머리, 흰 눈의 단발 여성 인간형 이변 | 감·간·곤을 산하에 둔다. 양과 유사한 태도. |

양·무극·음은 각각 세 부서를 산하에 두어 수적 균형을 이룬다.

## 사신수

청룡·백호·주작·현무는 네 방위를 지키며 황룡 자체에 충정을 바친다. 협회장 직위가 아니라 황룡에게 충성하므로, 대리인의 권한을 무시할 수 있다.
