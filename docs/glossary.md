# 용어집

| 용어 | 의미 |
|---|---|
| 이변 | 현실에 발생하는 초자연적·비현실적 이상현상. |
| 틈 | 공간형 이변의 입구. |
| 채널 | 같은 이변 안에서도 서로 만나지 못하는 층위 또는 공간 단위. |
| 서버 | 채널보다 상위의 묶음. |
| 블랙로즈 | 협회의 정식 명칭. |
| 협회 | 일반 이변 내부에서 블랙로즈를 지칭하는 현장용 명칭. |
| 성황당 | 본부와 사택 중앙에 있는 **신성한 나무(신목)**. 이동·귀환점 등록·조건부 부활과 연결된다. 건물이 아니다. |
| 팔괘 | 여덟 공식 부서에 부여된 상징 체계. |
| 무극 | 진·손 및 비공식 Null을 관할하는 상층 존재. 평소에는 장난스럽고 부드러운 인상이다. |
| Null | 무극 산하의 비공식 특수부서. |
| 이변탐사부 / 탐사A / 진 | 수칙서를 바탕으로 정식 탐사·구조·진압·회수를 수행하는 부서. |
| 사전답사부 / 탐사B / 손 | 최초 진입, 위험 정보 수집을 맡는 부서. |
| 수칙서 | 현장 기록을 바탕으로 연구·분석부가 작성하는 생존·대응 규칙. |
| 깃펜 | 협회원에게 귀속되어 1인칭 기록을 남기는 도구. |
| 금줄제례 | 서여울의 고유 영력. 본능과 대상을 봉인·억제한다. |
| 흑룡소각 | 김설하의 고유 영력. 기록·흔적·원인의 현실 반영을 태운다. |
| 액맥파열 | 이선의 통제 불가능한 특성. 서로 독립된 악재가 겹쳐 이변의 닫힌 규칙·결말을 어긋나게 한다. |
| 보급형 노리개 | 사형수 전형을 제외한 협회원에게 지급되는 개인용 정신 방호 장비. |
| 길들임 | 오랜 착용으로 노리개의 외형과 방호 기능이 주인에게 적응하는 변화. |
