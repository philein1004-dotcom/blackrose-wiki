# 부적과 제례 매개

현대 사회에서 부적은 대부분 미신이나 장식으로 취급되지만, 과거에는 실제 효력을 가진 부적 일부가 민간에 유통되었을 가능성이 있다. 협회에서 사용하는 부적은 모두 실재하는 영적 효력을 가진다.

## 용도

- 이변의 접근과 추적 방해
- 특정 규칙의 임시 봉인
- 공간과 개체의 경계 표시
- 제례 대상의 고정
- 영력의 저장과 방출

## 인물별 사용

- **서여울**: 금줄, 향, 피와 함께 금줄제례의 매개로 사용한다. 주로 본능과 대상을 봉인한다.
- **김설하**: 분석이 끝난 술식을 정밀하게 실행하고 흑룡소각의 범위를 제어한다. 준비된 상황에서 특히 강하다.
