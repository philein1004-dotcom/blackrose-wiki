# 대외 기관

블랙로즈는 공식적으로 존재하지 않는다. 현실 사회와 접촉할 때는 공보부가 관리하는 합법 기관의 얼굴을 빌린다.

| 기관 | 공개 역할 | 이면 역할 |
|---|---|---|
| 국민안전부 | 재난안전문자, 대피 안내, 국민 안전 행정 | 특수 재난안전문자를 통한 시험 초대, 이변 대피 지침, 정치·행정 위장 |
| 국제인문연구소 | 문화·언어·전설·신앙·민속 연구. 문과계 KAIST에 가까운 위상 | 이변의 금기, 민간신앙, 언어 규칙과 문화적 원형 분석. 연구자 다수는 실제 연결을 모를 수 있다. |
| 가람출판사 | 논문, 자료, 일반 도서, 괴담집 출판 | 이변 정보의 은닉·왜곡·배포와 연구 자료 유통 |

## 공보부와 이선

공보부는 단순 홍보 부서가 아니라 위 세 기관을 통한 외부 업무의 창구다. 이선은 이변 내부에 장기간 두면 사건이 커질 위험이 있으므로, **공보부 소속으로 국제인문연구소 관련 외부 업무를 수행하는 방향**이 적합하다.
