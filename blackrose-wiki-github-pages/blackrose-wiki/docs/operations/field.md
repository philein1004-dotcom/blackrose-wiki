# 현장 운용과 수칙서

블랙로즈의 수칙서는 연구실에서 완성되는 매뉴얼이 아니다. 사전답사부가 현장에서 죽거나 살아남으며 모은 기록을 기록부가 보존하고, 연구·분석부가 해석해 수칙서로 만든다.

## 표준 흐름

1. 이변 발생 또는 틈 확인
2. 사전답사부 투입
3. 위험 패턴, 사망 조건, 생존 조건 기록
4. 기록부가 자료를 저장·분류
5. 연구·분석부가 수칙서 초안 작성
6. 수칙서 개정과 위험도 조정
7. 이변탐사부가 정식 탐사·구조·진압·회수
8. 추가 기록을 다시 수칙서에 반영

## 수칙서의 윤리적 모순

수칙서의 정확도는 누군가 실제로 규칙을 어기고 죽었는가에 의해 높아진다. 따라서 협회는 사람을 살리기 위해 죽음을 기록하고, 더 나은 기록을 위해 가장 위험한 인원을 먼저 보낸다.

## 현장 명칭

| 정식 명칭 | 현장 호칭 |
|---|---|
| 블랙로즈 | 협회 |
| 공보부 / 인사부 / 연구·분석부 | 건 / 태 / 이 |
| 이변탐사부 / 사전답사부 | 진 / 손 |
| 관리부 / 기록부 / 후처리부 | 감 / 간 / 곤 |
