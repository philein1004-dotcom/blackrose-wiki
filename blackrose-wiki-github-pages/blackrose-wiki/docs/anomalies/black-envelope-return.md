# 검은 봉투 반송 사건

김설하가 연구·분석부에서 Null로 편입되는 계기가 된 별개의 이상 사건이다.

## 개요

협회 내부 우편망에 검은 봉투가 반복적으로 도착한다. 수신자는 매번 다르며, 봉투 안에는 수신자가 **아직 저지르지 않은 실수에 대한 징계 보고서**가 들어 있다. 보고서의 내용은 며칠 뒤 현실이 된다.

## 김설하의 분석

설하는 문장 구조, 도장 위치, 결재선과 사건 번호가 현재 협회 양식과 미묘하게 다르다는 점을 발견했다. 이 현상은 미래 예지가 아니라 **실패한 세계선의 행정 기록이 현재 협회로 역류하는 현상**이었다.

## 처리

1. 일부 보고서를 흑룡소각으로 태워 현실 반영을 끊는다.
2. 남은 기록을 대조해 공통 결재선과 사건 중심을 찾는다.
3. 아직 존재하지 않는 결재선을 역추적한다.
4. 공식 분류에 없는 부서, Null의 흔적에 닿는다.
5. 명령 없이 사건을 끝낸 뒤 사후 편입 통보를 받는다.

## 사건의 기능

이 사건은 Null이 사람을 선발하는 방식을 보여 준다. 설하는 Null을 찾아 지원한 것이 아니라, 빈칸을 견디지 못하고 이미 Null의 일을 수행해 버렸다.

## 미정 사항

- 최종 이변 등급과 피해 규모
- 실패한 세계선이 실제로 존재하는 방식
- 전소 단계 없이 사건을 닫을 수 있었는지
