# 이변 등급 체계

이변 등급은 **수칙서가 얼마나 안정적으로 작동하는가**와 **피해가 어디까지 확산될 수 있는가**를 별도로 표시한다.

## 수칙서 준수도

| 등급 | 의미 |
|---|---|
| 발단 | 수칙서가 대체로 정확하다. 규칙을 지키면 생존 가능성이 비교적 높다. |
| 전개 | 수칙서는 유효하지만 예외 상황이 생긴다. 현장 판단이 필요하다. |
| 위기 | 수칙서 일부가 맞지 않거나 서로 충돌한다. |
| 절정 | 이변이 수칙서를 역이용하거나 규칙이 실시간으로 흔들린다. |
| 결말 | 기존 수칙서가 사실상 무력화된다. 기존 규칙만으로 대응하기 어렵다. |

## 위험도

| 등급 | 피해 범위 |
|---|---|
| 기 | 개인 또는 소규모 피해. 비교적 관리 가능한 수준. |
| 승 | 건물, 시설, 특정 집단 단위의 피해 가능. |
| 전 | 지역 또는 도시 단위로 확산될 수 있음. |
| 결 | 국가적·문명적 피해 가능. 현실 질서 붕괴 위험. |

## 표기 예시

`위기-승`은 수칙서가 부분적으로 충돌하며, 건물 또는 특정 집단 규모의 피해가 예상되는 이변을 뜻한다.
