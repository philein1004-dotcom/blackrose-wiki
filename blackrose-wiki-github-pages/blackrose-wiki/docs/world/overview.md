# 핵심 전제

**블랙로즈**는 현대 한국을 기반으로 한 현대 판타지·나폴리탄 괴담·이상현상 관리 조직물이다. 현실의 행정, 언론, 출판, 연구 기관은 대부분 유지되지만 그 이면에는 과학적으로 설명되지 않는 초자연적 이상현상인 **이변**이 존재한다.

이야기의 중심 조직은 정식 명칭 **블랙로즈**, 현장 호칭 **협회**다. 이 조직은 인간이 이변을 정복하기 위해 세운 기관이 아니다. 인간형 이변 존재인 **황룡**이 인간과 이변 사이의 균형을 맞추기 위해 만든 장치에 가깝다.

## 정서와 장르

| 항목 | 내용 |
|---|---|
| 장르 | 현대 판타지, 나폴리탄 괴담, 이상현상 관리 조직물 |
| 핵심 정서 | 죽음, 기록, 죄책감, 생존, 균형 |
| 조직 미감 | 민속적 신성함과 회사식 관료제의 충돌 |
| 핵심 모순 | 사람을 구하려는 조직이 사람을 갈아 넣어 수칙서를 만든다 |

## 서사의 기록 방식

협회원에게 귀속된 **깃펜**은 각 인물의 1인칭 기록을 남긴다. 본편은 이 기록들이 업로드된 결과물로 해석할 수 있다. 기록은 전지적이지 않으며 서술자의 시야, 착각, 은폐와 누락에 종속된다.

- 서여울의 기록은 인간성과 이변성의 경계를 몸으로 보여 준다.
- 김설하의 기록은 분류·해석·소각을 통해 조직의 이면에 접근한다.
- 이선의 기록은 평범한 외부인의 시선으로 조직의 부조리와 법칙의 파열을 드러낸다.
