# 작가 전용 영역

이 폴더는 GitHub Pages 사이트에는 게시되지 않지만, **저장소가 공개 상태라면 GitHub에서 누구나 볼 수 있다.** 핵심 결말과 반전은 아래 방법 중 하나로 관리한다.

1. 이 저장소 자체를 비공개로 유지한다.
2. 공개 위키 저장소와 별개로 `blackrose-writer-vault` 비공개 저장소를 만든다.
3. 로컬의 `author-notes/private/` 폴더에만 저장한다. 이 경로는 `.gitignore`에 포함되어 있다.

현재 이 폴더에는 설정 정합성을 유지하기 위한 비밀도가 낮은 관리 문서만 포함한다.
