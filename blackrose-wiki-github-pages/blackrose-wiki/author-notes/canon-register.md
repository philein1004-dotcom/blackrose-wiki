# 캐논 등록부

| 항목 | 상태 | 최신 결정 |
|---|---|---|
| 서여울 소속 | 확정 | 사전답사부 소속, Null 관리 대상 겸 실전 투입 자산 |
| 서여울 고유 영력 | 확정 | 금줄제례 |
| 김설하 Null 입성 | 확정 | 서여울 파일이 아닌 검은 봉투 반송 사건 |
| 김설하 능력 구조 | 확정 | 출력 S급, 육체 E급, 흑룡소각 |
| 이선 특성 | 확정 방향 | 행운이 아니라 법칙을 찢는 악운 |
| 이선 배치 | 확정 방향 | 공보부 소속, 국제인문연구소 관련 외부 업무 |
| 성황당 위치 | 확정 | 본부와 사택에만 존재. 현장 즉시 귀환 불가 |
| 초련과 김설하 | 확정 | 직접적인 개인 관계 없음 |
| 비사형수 실패 처리 | 확정 | 기억 소거 후 일상 복귀 |
| 황룡 무력화 | 확정 방향 | 대리인의 소행에 의한 실제 무력화 |
